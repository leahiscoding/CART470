# Repository guidance

- Keep README.md as the project index.
- Store each weekly journal in journals/week-N.md. Never replace README.md with journal content.
- Keep the living learning contract in living-learning-contract.md.
- Preserve the author's journal and contract text when reorganizing files.
- Start new journal branches from the latest origin/main. scripts/new-journal.sh provides this workflow.
- New weekly entries should not require changes to the shared README.
